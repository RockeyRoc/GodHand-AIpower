# GodHand AIpower 1.4.0

GodHand 1.4.0 adds a defensive operations center to Comprehensive Operations. The Windows GUI and the existing authenticated MCP service share one operation catalogue, target authorization, task queue, cancellation path, evidence store, and report exporter.

The release adds 20 defensive capabilities for checking installed components; querying and configuring a GodHand-owned Fail2Ban jail; reviewing and changing an already-installed Watchbird configuration; checking or rolling back the existing PHP WAF switch; running Lynis audits, YARA scans, and AIDE integrity checks; and exporting evidence reports. Three built-in workflows collect evidence without automatically applying remediation. Missing target tools are reported and are never installed by GodHand.

The portable release includes the GodHand runtime and the existing Tabby/WinSCP tools. It contains only GodHand adapters for Fail2Ban, Watchbird, Lynis, YARA, and AIDE; those upstream programs are not bundled. Component sources and license notes are listed in [防御模块/SOURCES.md](../防御模块/SOURCES.md).

Local regression, HTTP MCP, stdio MCP, and GUI construction checks are recorded in [1.4.0 实现与验收](1.4.0-实现与验收.md). The defense adapter was tested with local fixtures and simulated SSH streams. This release has not yet been tested against a real isolated Linux host or real Fail2Ban, Watchbird, Lynis, YARA, or AIDE installations.
