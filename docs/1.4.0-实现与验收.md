# GodHand AIpower 1.4.0 实现与验收

## 已实现范围

1.4.0 在 1.3.0 的 GUI、目标库、任务服务和唯一 MCP 工具 `godhand(action, arguments)` 上增加独立防御适配层。防御中心提供 20 项能力：组件探测；Fail2Ban 查询、GodHand 专属 Jail、封禁/解封、白名单与回滚；Watchbird 状态、日志、统计、防护开关、配置回滚及现有 WAF 切换/恢复；Lynis 审计、YARA 扫描、AIDE 基线初始化/检查/显式提交；三种只收集证据的流程和报告生成。

管理端通过已保存的目标连接资料走 SSH。适配器只调用目标上已安装的程序，不安装依赖、不提供任意远程 shell；初次检查不启用处置策略。GUI 与 MCP 共用能力目录、权限校验、任务服务、取消和报告数据。来源与许可证记录见[防御模块/SOURCES.md](../防御模块/SOURCES.md)，功能与参数见[防御中心操作说明](防御中心.md)。

## 真实环境覆盖边界

当前没有可连接的隔离 Linux 目标或其 SSH 凭据，Docker 隔离环境也不可用。因此真实 Fail2Ban 封禁/解封及配置回滚、Watchbird 日志/开关与 WAF 切换恢复、真实 YARA 样本命中、真实 AIDE 新增/修改/删除差异、Lynis 实际输出解析均未完成；能力覆盖表将这些标为待隔离目标验收。测试报告不把模拟 SSH 或解析器夹具写成真实工具验证。

Watchbird 适配限于已安装目标的防护配置和日志，不包含上游流量重放或 Flag 替换。上游 README 提示其不建议用于比赛；使用者仍需遵守所在竞赛和目标环境规则。
