# GodHand 1.6.0

面向 Windows x64 的稳定发布候选。使用新包时保留原机子库和比赛目录，EXE 与 `_runtime` 必须来自同一构建。

## 主要变化

- Codex 默认 stdio 接入，保留 HTTP MCP，统一固定本机端口 18765；配置写入前备份并保留其他 MCP。
- AI 中枢提供服务状态、允许目标、接入诊断与配置预览；运行期间锁定范围设置。
- 机子库按稳定目标 ID 授权，连接修改需要重新选择权限；提供导入、更新、迁移和恢复检查。
- 新增窄参数 `attack_*` MCP 适配，复用现有本机分析和单轮目标操作；不自动提交 Flag。
- 任务、日志、幂等、取消、目标互斥与异常清理继续共用后台；技能和专项流程随包提供。
- 保留 Windows 原生 AoiAWD 服务、每目标隔离、SSH 回传与探针部署恢复；不承诺 1.7 的事件处置中心或后台比赛 Agent。
- 便携构建排除本地规划、绝对路径证据清单及个人运行数据，附文件清单与 SHA-256。

## 检查说明

源码回归覆盖认证、任务、HTTP/stdio、机子库、恢复、防御适配、攻击适配和发布边界。构建与冻结检查以本次发布补验记录为准。

本版测试不连接真实比赛靶机。本机模拟通过不等于比赛环境效果；部署前按实际题目检查 SSH、PHP 覆盖及 PWN 启动方式。

## 使用

解压完整便携包后运行 `GodHand.exe`，在 AI 中枢选择允许目标并写入 Codex 配置。默认保持既有用户数据目录，切换比赛前停止旧后台。
