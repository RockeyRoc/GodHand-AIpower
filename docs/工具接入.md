# 工具接入 · GodHand 1.6

在“工具管理 → 工具登记与任务”中搜索业务或外部工具、填写参数并启动。任务列表显示执行状态，选中后可查看日志或停止任务。

## 先配置所需程序

点击“工具路径”，为 Python、PHP、PowerShell 或 phpggc 选择本机文件，保存后刷新依赖。留空时，GodHand 依次检查 tools/ 扩展目录和系统 PATH。

便携包提供 Tabby、WinSCP。选中已保存的机子记录后，可从“机子管理”打开对应终端或文件管理器；SSH 是否连通在外部窗口查看。

普通 Python/PHP 脚本使用本机解释器。phpggc 需要 PHP CLI 和其脚本文件；工具页会显示具体缺少的依赖，可在赛前准备并重新检查。

## 运行已有工具

选中工具，在“参数 JSON”填写该工具要求的值，并选择目标标识，然后点击“启动”。例如 Python 脚本可使用：

    {"file":"C:/比赛 工具/check.py","args":["--label","有空格的名称"]}

参数以独立 argv 项传入。程序路径与工作目录需存在；超时或停止会清理该任务所属进程。需要长期保留窗口的终端或文件管理器使用内置 Tabby/WinSCP 入口。

“批量脚本 / PHP 工具”子页保留原有表单，与工具路径设置共用解释器。

## 登记自己的工具

点击“编辑定义”，修改 JSON 后点击“保存定义”。自定义记录保存在当前比赛目录的 tools.json。

    {
      "id": "site_check",
      "name": "站点检查",
      "kind": "script",
      "executable": "C:/Python/python.exe",
      "arguments": ["{file}"],
      "working_directory": "C:/比赛 工具",
      "parameters": {"file": {"type": "string"}},
      "dependencies": ["file"],
      "timeout": 60,
      "read_only": true
    }

按照实际程序填写 id、executable、参数及依赖。任务的产物位置在结果中查看，完整记录保存在当前比赛数据目录。

## 通过 AI 调用

action=tools 查询可用工具与依赖，action=run_tool 指定 tool、target、parameters。业务能力通过 capabilities 查询后使用 run。task、logs 和 cancel 与界面任务列表共用同一套记录。
