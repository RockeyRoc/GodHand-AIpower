# 工具接入

在“工具管理”登记程序或脚本，以 JSON 保存到管理数据目录的 tools.json。内置业务能力也在同一清单中，旧批量脚本、phpggc、PHP 禁用函数分析保留在第二个子页。

```json
{
  "id": "site_check",
  "name": "站点检查",
  "kind": "script",
  "executable": "C:/Python/python.exe",
  "arguments": ["{file}"],
  "working_directory": "C:/比赛 工具",
  "parameters": {"file": {"type": "string"}},
  "dependencies": ["file"],
  "timeout": 60,
  "read_only": true
}
```

运行参数示例：`{"file":"C:/比赛 工具/check.py","args":["--label","有空格的名称"]}`。每项独立传入 argv；不会经由 shell 拼接。程序路径和工作目录必须存在。超时或停止会结束该任务拥有的 Windows Job 进程树。正常完成后也会清理残留子进程，因此需要常驻的外部窗口程序使用内置 Tabby/WinSCP 入口。

Tabby、WinSCP 的目标来自“机子管理”中保存的记录。工具标记“已启动”表示进程创建完成，SSH 是否连通由外部程序显示。密码不放在启动参数中。

Python/PHP 脚本解释器由本机或扩展包提供；冻结应用内的 Python 运行时不作为用户脚本解释器。phpggc 需要 PHP CLI 和 `第三方工具/phpggc/phpggc`。缺少依赖时显示原因，比赛期间不自动下载。

任务状态、摘要、事件和产物位置可在“工具管理”查看。完整任务数据位于管理数据目录 tasks；事件数据库保留脱敏输出。工具自身写出的文件按其实现管理。

MCP 统一使用 godhand：action=tools 检查，action=run_tool 启动，arguments 填工具、目标及参数。

内置路径可在“工具路径”配置 Python、PHP、PowerShell 和 phpggc，无需改写内置工具定义。便携扩展目录为 tools/Python、tools/PHP、tools/PowerShell；批量脚本与 PHP 工具共用这些设置。详见 GodHand更新说明.md。
