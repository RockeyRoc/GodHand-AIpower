# 来源与鸣谢

GodHand 的业务基线来自用户导入的 YL Phantom（原作者 Wwlsyl）工程，保留其原有业务能力并增加工具管理和 MCP AI 中枢。当前产品统一使用 GodHand 名称；既有项目目录保留原路径。

部分通信字段、远程文件名与默认连接字段保留旧标识，以兼容已有部署。这些标识不作为产品名称展示。历史验收记录和原始基线哈希按原记录保留。

Logo 使用用户于本次会话提供的图片；PNG 保留原始透明图，ICO 从该图生成多尺寸图标。Tabby、WinSCP 和 Python 第三方依赖保留各自许可证及归属。原始工程未附明确完整发行许可，公开分发前应确认原作者及第三方许可要求。

1.4.0 新增防御适配器参考 Fail2Ban（GPL-2.0-or-later）、CyberStrikeAI（Apache-2.0）、Watchbird（AGPL-3.0）、Lynis（GPL-3.0）、YARA（BSD-3-Clause）和 AIDE（GPL-2.0-or-later）。GodHand 未复制或分发这些上游程序；只在授权 SSH 目标上调用已安装工具。CyberStrikeAI 仅作为参数目录、流程与报告结构的设计参考。Watchbird 源码头部另标记 `getFormData()` 为 CC-BY-NC-SA-4.0，GodHand 未复制该实现。详细来源及边界见[防御适配器来源与许可证](../防御模块/SOURCES.md)。

Watchbird 上游 README 提示该项目不用于比赛场景；此提示保留为来源信息，使用该 WAF 前需核对目标环境及赛事规则。
