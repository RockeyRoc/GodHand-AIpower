# 来源与鸣谢

GodHand 的 AWD 业务基线来自 Wwlsyl 的 YL Phantom 工程，在原有业务基础上加入工具管理、任务服务和 MCP AI 中枢。项目保留原作者归属，产品名称统一为 GodHand。

部分通信字段、远程文件名和默认连接字段沿用原标识，以兼容既有部署。历史验收记录与基线哈希按其原版本保留。

项目 Logo 使用用户提供的透明 PNG，ICO 由该图生成多个尺寸。Tabby、WinSCP、Python 依赖及其他配套组件保留各自许可证与归属。原始工程的发行许可资料按现有来源记录保留，分发时一并核对适用许可。

## 防御适配与监测

1.4 的防御适配参考 Fail2Ban、Watchbird、Lynis、YARA 和 AIDE，在目标上调用已安装工具。CyberStrikeAI 提供了能力目录、流程和报告结构方面的设计参考。

1.5 加入 AoiAWD 配套环境，Core、Web、MongoDB 在 Windows 本机运行，Linux 靶机使用对应探针。配套目录包含上游来源、原始与修改后的对应源码及许可文件。

具体版本、许可和适配内容见[防御模块来源](../防御模块/SOURCES.md)。Watchbird 上游的使用场景说明也在来源记录中保留；使用前结合目标环境与赛事规则选择相应工具。
